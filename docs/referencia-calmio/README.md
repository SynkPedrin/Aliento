# Referência: embudo original (Calmio)

Material extraído do embudo original do proprietário, para replicar outros programas no Alento.

- `catalog_es.json`: catálogo completo de textos em espanhol (3.428), de todos os produtos (tabaco, álcool, luto, divórcio, identidade, produtividade…), por código.
- `questions.json`: perguntas e opções do quiz de tabaco, na ordem.
- `smoking_type_texts.json`: os 36 textos de tipo de fumante (principal e principal-secundário).
- `members.json`: depoimentos da página de venda (nome, foto `card-XX`, citação).

O funil Sem Fumo já usa esse conteúdo em `server/content/funnels/sem-fumo-es.js` e `public/js/content/sem-fumo-es.js`.
